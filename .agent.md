# AI Agent Configuration for EcoCycle Webapp

> Configuration and capabilities for AI-assisted frontend development.

## 🤖 Agent Capabilities

### Code Understanding
- **React 17**: Hooks, context, component lifecycle
- **Redux & Redux-Saga**: State management, middleware, async effects
- **Material-UI 5.4+**: Component library, theming, styling
- **Formik + Yup**: Form state and validation
- **TypeScript**: Type definitions for React props and Redux state

### Development Tasks Agent Can Perform

✅ **Can Help With**:
- Creating Redux slices with actions and sagas
- Building React pages and form components
- Implementing MUI-based UI components
- Writing Formik forms with Yup validation
- Adding routes and navigation
- Refactoring components for reusability
- Implementing fieldsets (ProductItem, Value, Place, Media)
- Debugging Redux state with DevTools
- Writing tests with React Testing Library
- Styling with Styled Components and MUI

❌ **Not Recommended**:
- Changes to Redux state without saga pattern
- Direct API calls in React components
- Mutation of state outside Redux
- Major architectural changes without discussion

## 🛠 Recommended Skills

### Skill 1: Redux Slice & Saga Creation
**When**: Adding new domain feature (Products, Places, Vehicles)
**Process**:
1. Create slice with initialState, reducers, extraReducers
2. Define API service layer in `services/`
3. Create saga with generator functions
4. Wire saga to store in `store.ts`
5. Create page component using selectors + dispatch

### Skill 2: Form Component with Fieldsets
**When**: Creating data entry forms
**Process**:
1. Define Yup schema for validation
2. Create form component with Formik wrapper
3. Compose fieldsets for form sections
4. Use MUI + FormikMUI components
5. Wire submit handler to Redux action

### Skill 3: Page Component Integration
**When**: Wiring components with Redux state
**Process**:
1. Use `useAppSelector` to access state slices
2. Use `useAppDispatch` to dispatch actions
3. Handle loading/error states from Redux
4. Display data with tables or lists
5. Add modals/dialogs for CRUD operations

---

## 🔑 Key Concepts

- **Redux Slices**: Encapsulate state, reducers, and actions
- **Redux-Saga**: Middleware for side effects (API calls, timers)
- **Fieldsets**: Reusable form components (ProductItem, Value, Place)
- **Selectors**: Compute state slices for components
- **Material-UI**: Consistent, professional UI components
